# Система учета заказов в студенческой столовой

**Команда:** Манн В., Калмыкова С., Пичугина К., Антонова М.

**Проблема:** Очереди в столовой и путаница с заказами.
**Решение:** Telegram-бот с WebApp для предзаказа блюд.

## Роли в команде
*   **Frontend/Bot:** Разработка интерфейса WebApp, верстка, интеграция с ботом (Антонова М.)
*   **Backend:** Схема БД, каркас сервера (Калмыкова С.)
*   **AI/Data:** Разработка ML-функции (Пичугина К.)
*   **DevOps/QA:** Репозиторий, README, тестирование (Манн В.)

## Стек технологий
*   **Язык:** Python 3
*   **Бот:** Aiogram 3
*   **Бэкенд:** Aiohttp
*   **БД:** MySQL (PyMySQL)
*   **Фронтенд:** HTML, CSS, JavaScript (Telegram WebApp)

## Схема БД (4 таблицы)
*   `users` (id, имя, телефон)
*   `menu_items` (id, название, цена, категория, доступность)
*   `orders` (id, пользователь, статус, время самовывоза, сумма)
*   `order_items` (id заказа, id блюда, количество, цена)

## Статусы заказа
`new` -> `accepted` -> `cooking` -> `ready` -> `picked_up` / `cancelled`

## ML-функция
**Рекомендации «С этим берут»**. Модель будет анализировать историю заказов (таблица `order_items`) и предлагать пользователю дополнительные блюда на основе выбора других студентов.

## Запуск проекта
1. `pip install -r requirements.txt`
2. Заполнить `.env` данными (BOT_TOKEN, DB_HOST, DB_USER, DB_PASSWORD)
3. `python main.py`
4. Сайт доступен по адресу `http://localhost:8080` (или другому порту)
